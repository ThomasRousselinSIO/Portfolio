MovieZone

Explication générale du projet PHP
But : MovieZone est une application web qui permet de gérer une collection de films, leurs réalisateurs et leurs acteurs. Elle suit une organisation MVC simple : les requêtes passent par un point d'entrée, les contrôleurs coordonnent le traitement, les modèles dialoguent avec MySQL et les vues affichent le résultat.

1. Fonctionnement global

Navigateur -> public/index.php -> contrôleur -> modèle PDO -> base MySQL
                                                -> vue PHP -> HTML affiché

public/index.php est le routeur unique. Il lit le paramètre URL action et appelle la bonne méthode. Sans action, la page d'accueil affiche les films.

2. Rôle des dossiers

config/

database.php ouvre la connexion PDO vers MySQL, sur la base films, et active les exceptions en cas d'erreur.

controllers/

Reçoivent la requête, récupèrent les données envoyées, appellent les modèles, puis chargent une vue ou redirigent après une modification.

models/

Contiennent les requêtes SQL et les opérations sur les films, réalisateurs, acteurs et relations entre films et acteurs.

views/

Génèrent les pages HTML : accueil, formulaires, liste des réalisateurs et liste des acteurs. partials/ mutualise l'en-tête et le pied de page.

public/assets/

style.css définit l'apparence responsive. app.js valide certains champs, confirme les suppressions et bascule entre URL et fichier image.

sql/

Contient le script de création initiale de la base. Il sert de point de départ pour installer le stockage MySQL.

3. Actions disponibles

URL / actionRésultat
index.phpAffiche les films triés du plus récent au plus ancien.
?action=addAffiche le formulaire puis insère un film en POST. Une image peut venir d'une URL ou d'un upload.
?action=edit&id=...Charge un film, puis met à jour ses informations et ses acteurs associés.
?action=delete&id=...Supprime un film après confirmation côté navigateur.
?action=realisateursAffiche les réalisateurs, triés selon la meilleure note de leurs films.
?action=acteursAffiche les acteurs, avec le nombre de films et la meilleure note associée.
?action=add_realisateur / add_acteurAjoute une personne via un formulaire POST.

4. Données et relations

Un film possède un titre, un genre, une année, une note sur 10, une description, une image et éventuellement un réalisateur. Les acteurs sont liés aux films par une relation plusieurs-à-plusieurs :

realisateur (1) ---- (N) films (N) ---- (N) acteur
                                        via film_acteur

Lors de l'ajout ou de la modification d'un film, syncActeurs() supprime les anciens liens puis recrée la liste sélectionnée. Les requêtes avec paramètres utilisent PDO préparé, ce qui limite les injections SQL.

5. Traitement des images

  • Si un fichier est envoyé, le contrôleur crée public/assets/uploads/ si nécessaire, vérifie le type MIME autorisé et déplace le fichier avec un nom unique.
  • Sinon, il enregistre le lien saisi dans image_url.
  • La vue affiche ensuite cette valeur dans l'attribut src de l'image.

6. Points importants à connaître

Schéma SQL incomplet dans le fichier fourni : sql/films.sql crée actuellement uniquement la table films, sans la colonne id_realisateur ni les tables realisateur, acteur et film_acteur utilisées par le code. L'installation complète nécessite donc d'ajouter ces éléments avant d'utiliser toutes les fonctions.
  • Les formulaires d'édition ne proposent pas actuellement la sélection du réalisateur ni des acteurs, même si le contrôleur et le modèle savent les enregistrer.
  • La validation JavaScript améliore l'expérience, mais une validation serveur serait nécessaire pour sécuriser réellement les données.
  • Les sorties HTML devraient idéalement être échappées avec htmlspecialchars(), notamment les titres, descriptions et URLs.
  • La suppression passe par GET ; une action POST avec protection CSRF serait plus robuste en production.

Résumé

MovieZone est un CRUD PHP/MySQL organisé en MVC. Le routeur choisit une action, le contrôleur orchestre, le modèle exécute les requêtes et la vue affiche les données. Le cœur fonctionnel couvre les films, les personnes liées, les images et la gestion des relations film-acteur.
